VikingFit

A Viking-themed fitness companion with workout, nutrition, progress, coaching, challenge, and social features.

Fitness & feature help

  • Check your profile and unit preferences if weight or height values appear in the wrong units.
  • Camera and AR-based features require the appropriate iOS permissions.
  • Meal, food-scanning, clan, challenge, and social features may require an internet connection.
  • If a screen does not load correctly, return to the previous screen, reopen the app, and try again before contacting support.

VikingFit is a fitness and wellness tool and is not a substitute for professional medical advice.

Need help?

If you're having a problem with VikingFit, first fully close and reopen the app and make sure you are running the latest version available to you.

If the problem continues, contact Ginger B Games at gingerbgames@gmail.com.

When contacting support, it helps to include:

  • App name: VikingFit
  • Your iPhone model and iOS version
  • The app version, if known
  • A short description of what happened
  • The screen, mode, or feature where it happened
  • A screenshot, if it helps explain the issue

Common troubleshooting

  • Fully close the app and reopen it.
  • Restart the iPhone if audio, haptics, camera, motion, or other device features appear stuck.
  • Check the app's Settings screen for relevant options.
  • If an update is available, install the newest App Store version.
  • If the issue continues, contact support before deleting the app if you want to preserve locally stored progress or settings.
