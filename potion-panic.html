Official Game Support

Potion Panic

Fast, colorful potion-brewing arcade play built around matching falling ingredients to the current cauldron color, building streaks, and unlocking local achievements.

Gameplay help

  • Watch the cauldron and current potion color before tapping an ingredient.
  • Tap ingredients that match the active potion color and avoid mismatches.
  • The game becomes faster as a run continues.
  • Achievements and cosmetic unlock progress are stored locally on the device.
  • If an achievement appears incorrect, close and reopen Potion Panic and check the Awards screen again.

Need help?

If you're having a problem with Potion Panic, first fully close and reopen the app and make sure you are running the latest version available to you.

If the problem continues, contact Ginger B Games at gingerbgames@gmail.com.

When contacting support, it helps to include:

  • Game name: Potion Panic
  • Your iPhone model and iOS version
  • The app version, if known
  • A short description of what happened
  • The screen, mode, or feature where it happened
  • A screenshot, if it helps explain the issue

Common troubleshooting

  • Fully close the app and reopen it.
  • Restart the iPhone if audio, haptics, camera, motion, or other device features appear stuck.
  • Check the app's Settings screen for relevant options.
  • If an update is available, install the newest App Store version.
  • If the issue continues, contact support before deleting the app if you want to preserve locally stored progress or settings.
