Official Game Support

Candy Cascade

Portrait candy-merging puzzle built around a cauldron, escalating merges, score chasing, and overflow survival.

Need help?

If you're having a problem with Candy Cascade, first try closing and reopening the app and make sure you are running the latest version available to you.

If the problem continues, contact Ginger B Games at gingerbgames@gmail.com.

When contacting support, it helps to include:

  • Game name: Candy Cascade
  • Your iPhone model and iOS version
  • A short description of what happened
  • The screen or game mode where it happened
  • A screenshot, if it helps explain the issue

Common troubleshooting

  • Fully close the app and reopen it.
  • Restart the iPhone if audio, haptics, or motion behavior appears stuck.
  • Check the game's Settings screen for music, sound-effects, haptic, or gameplay options.
  • If an update is available, install the newest App Store version.
