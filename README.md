# Ginger B Games Support Site

Official GitHub Pages support/privacy site for Ginger B Games.

## IMPORTANT BEFORE PUBLISHING
Replace this placeholder everywhere:

gingerbgames@gmail.com

with the exact Ginger B Games support Gmail address.

There is one occurrence in each HTML page/footer/contact section.

## Main files
- index.html — support homepage
- privacy.html — universal privacy policy
- styles.css — shared site styling
- one HTML support page per game

## GitHub Pages
Publish from:
- Branch: main
- Folder: /(root)

After GitHub Pages is live, your main support URL will normally look like:
https://YOUR-GITHUB-USERNAME.github.io/gingerb-games-support/

Individual support URLs will end in:
- /starglass.html
- /ninja-dojo.html
- /midnight-munch.html
...and so on.
